# リークチェックリスト（特徴量・評価の未来情報混入を防ぐ）

「儲かる競馬予測」の公開手法調査（2026-10-23）で確認された頻出リーク8類型と、
このリポジトリでの対策・担保方法をまとめる。新しい特徴量や評価方法を追加する
ときは、このリストでセルフチェックしてから実装すること。

## リーク8類型と対策

### 1. 対象レース自体の混入
- **内容**: 検証対象レースの前走成績などに、そのレース自体の情報が含まれる。
- **対策**: 特徴量の集計は「対象レースの発走日時より前」のレースだけに限定する。
  集計関数には必ず基準日時を引数で渡し、DB の WHERE 句で `race_date < 対象日`
  （同日開催は時刻不明のため含めない）を徹底する。

### 2. 全期間集計（as-of 違反)
- **内容**: 騎手・調教師・種牡馬の勝率などを全期間で集計して特徴量化すると、
  未来の成績が過去の予測に混入する。
- **対策**: 集計は expanding window（対象日より前のみ）で行う。
  `metrics/horse_metrics` のような累積テーブルを予測に使う場合は、
  「いつの時点までの集計か」を必ず確認すること。現行の horse_metrics は
  全期間集計のため、**現行のまま時系列検証の特徴量に使ってはいけない**
  （Phase 3 で as-of 化する）。

### 3. 確定オッズの特徴量化
- **内容**: 発走直前にしか分からない確定オッズを特徴量に入れると、
  実運用（購入時点）では再現できない精度が出る。
- **対策**: オッズを特徴量に使う場合は、購入判断時点で取得可能な値
  （前日オッズ等）に限定し、どの時点のオッズかを明記する。
  オッズと払戻の取り違えは `leak_checks.check_win_payout_identity`
  （恒等式: 払戻 ≒ 単勝オッズ×100）で検出できる。

### 4. 時系列オッズの受信可能性
- **内容**: オッズの時系列変化など、発走前に取得できなかった情報の混入。
- **対策**: 特徴量ごとに「発走前のどの時点で取得可能か」を下の表で管理する。

### 5. 後知恵選別
- **内容**: 結果を見てから条件（開催場・距離・人気帯など）を絞ると
  見かけの回収率が上がる。
- **対策**: 買い条件は `betting_conditions.yaml` に事前登録し、
  検証結果を見てから変えない。変える場合は封印期間で再評価する。

### 6. 多重検定
- **内容**: 閾値・戦略を何十通りも試して最良のものだけ報告する。
- **対策**: 試した戦略の総数を記録する。回収率は必ず信頼区間
  （`metrics.bootstrap_roi_ci`）と Top5レース除外版
  （`metrics.roi_excluding_top_races`）を併記する。

### 7. データ汚染・合成データの混入
- **内容**: デモデータ・合成データで学習/評価すると現実と無関係な結果になる。
- **対策**: `app/demo_data.py` の生成データは UI デモと単体テスト専用。
  本番評価は実データでのみ行い、データの出所を記録する。

### 8. ランダム分割によるリーク
- **内容**: 時系列データをランダムに train/test 分割すると未来が学習側に漏れる。
- **対策**: 評価は `evaluation/walk_forward.py` の expanding window 分割のみ。
  学習期間が検証期間より前であることはコード内で assert している。
  最終評価期間は holdout として封印し、明示フラグなしでは評価に含めない。

## 特徴量の取得可能時点（記入表）

新しい特徴量を追加したら、ここに取得可能時点を追記すること。

| 特徴量グループ | 取得可能時点 | 備考 |
|---|---|---|
| 馬の過去成績（着順・勝率） | 対象レースの前日まで | as-of 集計が前提（類型2） |
| 騎手・調教師成績 | 対象レースの前日まで | 同上 |
| 馬体重 | 発走約30分前 | 購入タイミング次第で使用不可になりうる |
| オッズ（確定） | 発走直前 | 特徴量として使う場合は類型3に注意 |
| 人気順 | 発走直前（オッズから導出） | オッズと整合性チェックあり |
| 着順・払戻金 | レース確定後 | **特徴量への使用は絶対禁止** |

## コード化されたチェック（evaluation/leak_checks.py）

| チェック | 内容 |
|---|---|
| `check_win_payout_identity` | 恒等式: 単勝払戻 ≒ 単勝オッズ×賭金（切り捨て誤差10円未満） |
| `check_race_integrity` | 勝ち馬は各レース1頭 / オッズ1.0倍以上 / 確定着順の重複なし |
| `check_popularity_odds_consistency` | 1番人気 = レース内最小オッズ |
| `check_temporal_separation` | 学習期間 < 検証期間 |
