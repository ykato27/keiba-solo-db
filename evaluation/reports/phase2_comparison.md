# Phase 2 ウォークフォワード比較レポート

## 前提と解釈の限界（最初に読むこと）

- 払戻データがDBに無いため、単勝払戻は **確定オッズ × 100円** で近似している（実際の払戻は10円未満切り捨て等のため、実績より最大で1点あたり10円未満だけ高く出る）。
- 現行DBの着順は **上位3着までしか記録されていない**。勝ち馬が記録されたレースに限り、未記録の出走行は「4着以下」として扱った。勝ち馬が記録されていないレースは除外した。
- データは合成データ中心とみられ、標本も小さい（下表）。ここでの回収率は「実データでの収益性」を示すものではなく、検証基盤とポリシーの動作確認が目的である。
- 封印期間（holdout: 2025-09-01 以降）は開封していない。評価した最大の日付は 2025-08-31。

## データ整合性の診断（最重要の発見）

現行DBは、以下のとおり生成規則が決定的なデモ／合成データであり、**実力評価には使えない**。本レポートの数値は、検証基盤とポリシーが機械的に正しく動くことの確認としてのみ意味を持つ。結論として、意味のある評価には実データの投入（Phase 4）が前提になる。

| 診断項目 | 結果 | 意味 |
|---|---:|---|
| 勝ち馬が馬番1番である割合 | 100.0% | 勝ち馬が常に1番。モデルは馬番だけで完全分離できてしまう |
| 人気と着順が一致する割合（記録行） | 100.0% | 人気 = 着順そのもの。「1番人気買い」の的中率100%はこのため |
| 1番人気の勝率 | 100.0% | 実データの1番人気勝率は30%前後。100%はあり得ない |
| ユニークな馬の数 | 127 頭（出走 16,771 行） | 馬IDが使い回されている |
| 勝ち馬の平均オッズ / 全体の平均オッズ | 26.5 / 26.6 | オッズは結果と無相関な一様ノイズ。ベタ買い回収率が100%を超えるのはこの算術のため |

## 事前登録した買い条件（この評価で使った値）

- 券種: win（払戻率の前提 0.8）
- EV閾値: 1.2 / 予測勝率下限: 0.1
- 大穴回避: 単勝オッズ 50.0 倍以上は買わない
- 1レース最大点数: 2 / 1点 100円
- Kelly: 分数 0.25、較正済み確率でのみ有効 （requires_calibration=True）
